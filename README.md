# DAW Workstation (nome provisório)

Digital Audio Workstation profissional para Windows, em desenvolvimento.

**Estado:** fase de fundação. Ainda não existe aplicação funcional.

## Requisitos de desenvolvimento

- Windows 10/11 x64
- Git
- Visual Studio 2022 com "Desenvolvimento para desktop com C++"
- CMake
- JUCE (versão a confirmar)

- `CLAUDE.md` — regras do projeto para assistentes de programação.
